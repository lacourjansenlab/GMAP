GMAP.src.tools.MapReader module#

class GMAP.src.tools.MapReader.Map(mapdir)#

Bases: object

Contains all information regarding a single map.

In this context, a map is as defined in the computational spectroscopy community - a way of estimating the properties of a functional group. It is not a python object.

Note

Users of the program are probably looking for the adding a new map page.

find_refpars(Printer)#

Creates a RefPars object for the map-specific parameters

A map is not required to have any specific parameters. But if it has them, they are supposed to be in a reference parameter file of the same format as the one of GEM itself.

Looks inside self.directory for a file of the name parameters.ref, If found, the resulting RefPars object is stored as the self.RefPars attribute.

Parameters:
PrinterPrinter

The object that allows to cleanly log and print during runtime, and handle errors.
