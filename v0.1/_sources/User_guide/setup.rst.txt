##########
GMAP Setup
##########

GMAP Setup can be used to copy the sourcefiles and the maps directories to another user specified directory in order to make it easier for them to modify the files in those directories.

In order to use this function, GMAP Setup [target directory] should be typed into the command line. This will copy the files into the inserted directory. The target directory may be given using either an absolute or a relative path but it must exist, for now. The target directory must also not contain files named sourcefiles_copy or maps_copy.
