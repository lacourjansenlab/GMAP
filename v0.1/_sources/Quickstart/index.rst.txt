Running GEM
========================================

1. If you have an environment, acivate it (name of the env_GMAP directory might be different on your system):
   - Unix: ``source env_GMAP/bin/activate``
   - Windows: ``env_GMAP\Scripts\activate.bat``
2. Navigate to the folder where your input file is located.
3. Assuming your input file is named ``input_GMAP.txt``, typing ``GMAP GEM run input_GMAP.txt`` will start the program and run the calculation.
4. After you're finished with the calculation, typing ``deactivate`` will close the environment again.
