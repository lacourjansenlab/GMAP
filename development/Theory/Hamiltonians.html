Hamiltonians#

Use Case#

The main reason to use GMAP is to obtain the Hamiltonians and transition dipole moments describing the energy landscape of chromophores and their interaction with each other and light. The Hamiltonian contains the frequency at which each chromophore absorbs light, and the couplings between these chromophores describe how strongly each of these chromophores talk to each other and thus influence each others absorption frequency. For instance, this treatment of molecules and their mutual interactions allows one to investigate the exciton landscapes of molecular aggregates. GMAP does not calculate the spectra, however, programs like NISE can compute absorption spectra, two-dimensional correlation spectra and other observables and properties using the output generated by GMAP.

Physical description#

The Hamiltonian is given by the following equation [1]:

\[H(t) = \sum_n \epsilon_n(t)B_n^\dagger B_n - \frac{1}{2}\sum_n \Delta_n(t)B_n^\dagger B_n^\dagger B_nB_n+ \sum_{n,m} J_{nm}(t)B_n^\dagger B_m - \sum_n \vec{E}(t)\cdot \vec{\mu}_n(t)[B_n^\dagger + B_n] ,\]

where \(B_n^\dagger\) and \(B_n\) are the creation and annihilation operators respectively. \(\epsilon_n(t)\) represents the energy gap between the ground state and the first excited state in a chromophore \(n\). The coupling strength of a chromophore \(n\) with the external electric field \(\vec{E}(t)\) is affected by the transition dipole \(\mu_n\). The anharmonicity \(\Delta_n(t)\) is the difference in energy energy gaps between the ground and first excited states and the first excited and second excited states, when considering the chromophores as three level systems. A positive anharmonicity indicates that the latter is smaller than the former. \(J_{nm}(t)\) represents the coupling between chromophores \(n\) and \(m\). The time-dependent electric field, \(\vec{E}(t)\), is not a system property and not considered by GMAP. The coupling and transition dipoles dependent on time, as the physical structure from which we derive the Hamiltonian is not necessarily static and can change over time.

GMAP obtains some of the terms in this equation, which are then used by programs like NISE to compute spectral observables and excitonic properties. The program works by using maps which use physical characteristics of the system to compute the values that make up the Hamiltionian trajectory. The way these maps work and how to add them to the program is explained here.

An example Hamiltonian with \(n\) chromophores is given below. \(\epsilon_m\) represents the frequency of the \(m\) th chromophore. \(J_{kl}`\) is the coupling between the \(k\) th and the \(l\) th chromophores. Note that \(J_{kl}\) and \(J_{lk}\) are identical. In the following the number of chromophores is \((N)\).

\[\begin{split}\begin{pmatrix} \epsilon_1 & J_{12} & J_{13} & J_{14} & ... & J_{1N} \\ J_{21} & \epsilon_2 & J_{22} & J_{24} & ... & J_{2N} \\ J_{31} & J_{32} & \epsilon_3 & J_{34} & ... & J_{3N} \\ J_{41} & J_{42} & J_{43} & \epsilon_4 & ... & J_{4N} \\ ... & ... & ... & ... & ... & ... \\ J_{N1} & J_{N2} & J_{N3} & J_{N4} & ... & \epsilon_N \end{pmatrix}\end{split}\]

File layout#

Each frame has its own Hamiltonian. In the txt format, each frame has its own line. Thus, after each Hamiltonian a new line is started. The first number on each line is the number of the frame. Then, the values that make up the Hamiltonian follow. As the Hamiltonian is a matrix which is symmetrical across the diagonal, only half of the couplings need to be written saving almost a factor two in storage space. The Hamiltonian is written starting at the diagonal entry followed by the couplings beween the first unit and all the other units. The number of entries total in the Hamiltonian stored this way is the triangular number of the size of the Hamiltonian (\((N+1)(N)/2\)). The values of the Hamiltonian are the expected frequencies in wavenumbers [cm \(^{-1}\) ]. These diagonal elements are frequencies that include electrostatic effects from the environment. The off-diagonal elements of the Hamiltonian denote the coupling between chromophores, which can be both positive and negative.

Thus the Hamiltonian trajectory in text format looks like:

0 \(\epsilon_1\) \(J_{12}\) \(J_{13}\) \(J_{14}\) … \(J_{1N}\) \(\epsilon_2\) \(J_{23}\) \(J_{24}\) … \(J_{2N}\) … \(\epsilon_N\)
1 \(\epsilon_1\) \(J_{12}\) \(J_{13}\) \(J_{14}\) … \(J_{1N}\) \(\epsilon_2\) \(J_{23}\) \(J_{24}\) … \(J_{2N}\) … \(\epsilon_N\)
2 \(\epsilon_1\) \(J_{12}\) \(J_{13}\) \(J_{14}\) … \(J_{1N}\) \(\epsilon_2\) \(J_{23}\) \(J_{24}\) … \(J_{2N}\) … \(\epsilon_N\) | … …
m \(\epsilon_1\) \(J_{12}\) \(J_{13}\) \(J_{14}\) … \(J_{1N}\) \(\epsilon_2\) \(J_{23}\) \(J_{24}\) … \(J_{2N}\) … \(\epsilon_N\)

Where \(m\) is the number of Hamiltionians. \(J_{kl}\) and \(\epsilon_n\) keep the same meaning as in the Hamiltonian above, except now they are per frame in the trajectory.

The binary file contains only 32-bit floats. The first one indicates the frame number, which is still a 32-bit float even though it represents an integer, and is followed by the Hamiltonian entries that belong to that frame number. After one Hamiltonian has been written, no spacer is used: the next float is the number of the next frame. Thus, in binary format the Hamiltonian trajectory looks like:

0 \(\epsilon_0\) \(J_{01}\) \(J_{02}\) \(J_{03}\) … \(J_{0N}\) \(\epsilon_1\) \(J_{12}\) \(J_{13}\) … \(J_{1n}\) … \(\epsilon_n\) 1 \(\epsilon_0\) \(J_{01}\) \(J_{02}\) \(J_{03}\) … \(J_{0n}\) \(\epsilon_1\) \(J_{12}\) \(J_{13}\) … \(J_{1n}\) … \(\epsilon_n\) 2 \(\epsilon_0\) \(J_{01}\) \(J_{02}\) \(J_{03}\) … \(J_{0n}\) \(\epsilon_1\) \(J_{12}\) \(J_{13}\) … \(J_{1n}\) … \(\epsilon_n\) … … m \(\epsilon_0\) \(J_{01}\) \(J_{02}\) \(J_{03}\) … \(J_{0N}\) \(\epsilon_1\) \(J_{12}\) \(J_{13}\) … \(J_{1N}\) … \(\epsilon_N\)

Where \(m\), \(J_{kl}\) and \(\epsilon_N\) keep the same meaning as in the representation of the text trajectory above.

The transition dipole moments are stored in a separate file. The values are given in the units of Debye. Similar to the Hamiltonian in the text format, the transition dipoles are written to a file where every each line contains the transition dipoles for one frame. Note that first all the x-components of the vectors are stored together, then all the y-components and finally all the z-components.

The transition dipole in the text format looks like:

0 \(\mu_{1,x}\) \(\mu_{2,x}\) \(\mu_{3,x}\) … \(\mu_{N,x}\) \(\mu_{1,y}\) \(\mu_{2,y}\) \(\mu_{3,y}\) … \(\mu_{N,y}\) \(\mu_{1,z}\) \(\mu_{2,z}\) \(\mu_{3,z}\) … \(\mu_{N,z}\)
1 \(\mu_{1,x}\) \(\mu_{2,x}\) \(\mu_{3,x}\) … \(\mu_{N,x}\) \(\mu_{1,y}\) \(\mu_{2,y}\) \(\mu_{3,y}\) … \(\mu_{N,y}\) \(\mu_{1,z}\) \(\mu_{2,z}\) \(\mu_{3,z}\) … \(\mu_{N,z}\)
… …
m \(\mu_{1,x}\) \(\mu_{2,x}\) \(\mu_{3,x}\) … \(\mu_{N,x}\) \(\mu_{1,y}\) \(\mu_{2,y}\) \(\mu_{3,y}\) … \(\mu_{N,y}\) \(\mu_{1,z}\) \(\mu_{2,z}\) \(\mu_{3,z}\) … \(\mu_{N,z}\)

As for the Hamiltonian the binary file contains only 32-bit floats. The first one indicates the frame number, which is still a 32-bit float even though it represents an integer, and is followed by the transition dipole entries that belong to that frame number. After one frame has been written, no spacer is used: the next float is the number of the next frame.
