1""" 

2Keeps track of files and file locations. 

3 

4This module does not actually parse file contents. It really just keeps 

5track of where relevant files are stored, and tries to find any 

6desired files. 

7 

8Classes 

9------- 

10FileLocations 

11 A singleton that stores the locations most important to the program. 

12 Does not contain user choices (those are taken care of by the 

13 parameter_parser module), but rather what the environment looks 

14 like. 

15 

16Functions 

17--------- 

18find_exec_os 

19 Determines on what platform GMAP is running. 

20get_file 

21 Given the diffent parameter sources, look for a file provided for 

22 the given parameter. Sources are checked in order of importance for 

23 the definition of the parameter. 

24get_bare_file 

25 Like get_file, but without having to consider directories, too. 

26get_def_parfile 

27 Fetches the default parameter file. Path is looked up, file is 

28 tested for existing and readability. 

29try_file 

30 Checks if the given location exists and is a file. 

31check_file_readability 

32 Checks if a given file can be read. 

33write_output 

34 Write all output for a single frame to files. 

35write_single 

36 Write a single datastructure to files of give name. 

37clear_output 

38 Prepare an empty file for each output, possibly clearing existing 

39 files. 

40clear_single 

41 Clears any file if it exists prior to writing. 

42write_legend 

43 Writes the contents of the legend output file. 

44write_parameter_file 

45 Writes the contents of the parameter output file. 

46write_single_parameter_source 

47 Writes the parameters from a single source to the parameter output 

48 file. 

49write_parameter_header 

50 Write the header of the next parameter source to the output file. 

51get_full_parameter_name 

52 Figure out what name the parameter should be saved as. Necessary for 

53 when a parameter belongs to a map, and not GMAP itself. 

54write_parameter_line_main 

55 Manages the writing of a single parameter to the parameter file. 

56 Does this by detecting the relevant case, and calling the relevant 

57 function. 

58write_parameter_line 

59 Writes a single parameter to the parameter file. For simple cases. 

60write_parameter_intersect 

61 Writes a single parameter to the parameter file. For when there's 

62 multiple different parameters that are mutually exclusive. 

63merge_files 

64 Merges output files from multiple runs. Needed for when running 

65 in parallel. 

66fname_to_tempname 

67 Generates the temporary file names used for parallel threads.

96 """Stores a frozen, singleton collection of environment variables. 

97 

98 Intended to be called very early (currently, this is the very first 

99 object created by GMAP), it saves information about the context of 

100 this run. File paths, dates, command line arguments, and more. 

101 

102 .. important:: 

103 While not specifically stated, any of the attributes defined 

104 in the code below this docstring (but above the  

105 `def __post_init__` line), can be used as parameters when 

106 instantiating this class for the first time. 

107 

108 This is relevant for the instr attribute. During normal GMAP 

109 usage, the :func:`~GMAP.src.tools.cmd_interface.cmd_interface` 

110 will do the instantiation of this class, and overwrite the instr 

111 attribute with a copy of the command used to call the function. 

112 

113 When this function is used as an entry point instead of a 

114 subprocess-assisted call from outside, the instr (and thus 

115 instruction) attribute will be different from the cmd (and thus 

116 callcommand) attribute. 

117 

118 Attributes

121 A static copy of sys.path.

126 A static copy of sys.argv, although in most runs this one is set 

127 in :func:`~GMAP.src.tools.cmd_interface.cmd_interface`, allowing 

128 a different value. 

129 Not intended to be used outside this class, use `instruction` 

130 instead. 

131 start : int 

132 Time at which the program started in nanoseconds. 

133 script_dir : `pathlib.Path` 

134 The location where GMAP is stored/installed. 

135 cwd : `pathlib.Path` 

136 The current working directory at the time of calling the 

137 program. 

138 now : `datetime.datetime` 

139 Roughly when the code started. Most likely you will not want to 

140 use this one, but `now_str` instead. 

141 refparfilename_hc : str 

142 hard coded file name for the reference parameter file. 

143 callcommand : str 

144 The str representation of cmd for later use. 

145 instruction : str 

146 The str representation of instr for later use. 

147 now_str : str 

148 A safe, filesystem-independent string representation of `now`. 

149 sourcedir_hc : `pathlib.Path` 

150 The hardcoded default directory for the sourcefiles (c library, 

151 reference parameter file, etc) 

152 mapdir_hc : `pathlib.Path` 

153 The hardcoded default directory for storing maps. 

154 exec_os : str 

155 The OS on which GMAP is currently running. Will take one of the 

156 following values: 

157 Win32bit, Win64bit, MacOS, Linux. 

158 clib_extension : str 

159 When looking for pre-built C libraries, this is what the

162 Options:

251def find_exec_os(): 

252 """Determines which os the system is running on. 

253 

254 Returns 

255 ------- 

256 exec_os : str 

257 The platform on which the program runs. Might be 32- or 64 bit Windows, 

258 Linux, or MacOS. 

259 """ 

260 

261 exec_os = None 

262 

263 if sys.platform == "win32": 

264 bits = ct.sizeof(ct.c_void_p)*8 

265 if bits == 32: 

266 exec_os = "Win32bit" 

267 elif bits == 64: 

268 exec_os = "Win64bit" 

269 else: 

270 GM_pt.Printer.warning( 

271 "\nEnvironment was determined to be windows, but it is " 

272 "neither a" 

273 f" 32, nor 64 bit version. It appears to be {bits} bit. Please" 

274 " contact the developers to solve this.", 

275 "howtogethere", True, GMAPerrclass=GM_ex.GmapOSError 

276 ) 

277 elif sys.platform == "darwin": 

278 exec_os = "MacOS" 

279 elif sys.platform == "linux": 

280 exec_os = "Linux" 

281 else: 

282 GM_pt.Printer.warning( 

283 f"\nexecuting OS not recognised... sys.platform = {sys.platform}. " 

284 "Please contact the developers to solve this. ", 

285 "howtogethere", True, GMAPerrclass=GM_ex.GmapOSError 

286 ) 

287 

288 return exec_os

291def get_file( 

292 dir_parname, file_parname, dir_hc, files_hc, 

293 cmd_pardict, pardicts=[], parfilelocs=[] 

294): 

295 """Determine the path to a file given all input sources 

296 

297 As there are 4 places that might store information regarding the 

298 file's path, each of which can contain 2 bits of information, which 

299 don't both have to be there, the dicision tree is somewhat complex, 

300 see the devnotes file for a table on what parameters are used in 

301 which case. 

302 

303 The naively found path is returned, but not checked for existence or 

304 validity. That is a separate step the caller should invoke. 

305 

306 .. seealso:: 

307 :func:`get_bare_file` 

308 Does the same, but for files which are not assumed relative 

309 to a path stored in another parameter. 

310 :func:`try_file` 

311 Checks the existence and file-ness of a given path. 

312 :func:`check_file_readability` 

313 Checks whether the given file can actually be read. 

314 

315 Parameters 

316 ---------- 

317 dir_parname : str 

318 The name of the parameter storing the directory path to which 

319 the desired parameter path is assumed relative to. 

320 file_parname : str 

321 The name of the parameter storing the path of the desired file. 

322 dir_hc : `pathlib.Path` 

323 In case the parameter in `dir_parname` does not exist in any of 

324 the given inputs, use this one. 

325 files_hc : list of `pathlib.Path` 

326 In case the parameter in `file_parname` does not exist in any of 

327 the given inputs, use this one. 

328 cmd_pardict : dict 

329 The dict storing all parameter choices from the command line. 

330 pardicts : list of dicts, default=[] 

331 All dicts storing parameter choices, ordered by importance - if 

332 a parameter is found in a dict earlier in the list, don't use 

333 any occurences later in the list. 

334 parfilelocs : list of `pathlib.Path`, default=[] 

335 The paths to the files whose contents are in the pardicts list, 

336 in the same order. 

337 

338 Returns 

339 ------- 

340 names : list of `pathlib.Path` 

341 The path to the desired file. 

342 file_is_hc : bool 

343 Whether the dir_hc/file_hc fallback had to be used. 

344 """ 

345 

346 file_is_hc = False 

347 dicts = [cmd_pardict] 

348 flocs = [FileLocations.cwd] 

349 

350 for dict_, floc in zip(pardicts, parfilelocs): 

351 if dict_: 

352 dicts.append(dict_) 

353 flocs.append(floc.parent) 

354 

355 for ix, (dict_, floc) in enumerate(zip(dicts, flocs)): 

356 if dir_parname in dict_: 

357 dirname = floc / dict_[dir_parname][0] 

358 for dict_ in dicts[ix:]: 

359 if file_parname in dict_: 

360 filenames = dict_[file_parname] 

361 break 

362 else: 

363 filenames = files_hc 

364 break 

365 elif file_parname in dict_: 

366 dirname = floc 

367 filenames = dict_[file_parname] 

368 break 

369 else: 

370 dirname = dir_hc 

371 filenames = files_hc 

372 file_is_hc = True 

373 

374 names = [dirname / name for name in filenames] 

375 

376 return names, file_is_hc

379def get_bare_file( 

380 file_parname, files_hc, floc_hc, cmd_pardict, pardicts=None, 

381 parfilelocs=None 

382): 

383 """Determine the path to a file given all input sources 

384 

385 There are 4 places that might store information regarding the file's 

386 path, which should be considered in a set order. 

387 

388 The naively found path is returned, but not checked for existence or 

389 validity. That is a separate step the caller should invoke. 

390 

391 .. seealso:: 

392 :func:`get_file` 

393 Does the same, but for files which are assumed relative to a 

394 path stored in another parameter. 

395 :func:`try_file` 

396 Checks the existence and file-ness of a given path. 

397 :func:`check_file_readability` 

398 Checks whether the given file can actually be read. 

399 

400 Parameters 

401 ---------- 

402 file_parname : str 

403 The name of the parameter storing the path of the desired file. 

404 file_hc : list of `pathlib.Path` 

405 In case the parameter in `file_parname` does not exist in any of 

406 the given inputs, use this one. 

407 floc_hc : `pathlib.Path` 

408 The base location from where the paths should be taken. 

409 cmd_pardict : dict 

410 The dict storing all parameter choices from the command line. 

411 pardicts : list of dicts, default=[] 

412 All dicts storing parameter choices, ordered by importance - if 

413 a parameter is found in a dict earlier in the list, don't use 

414 any occurences later in the list. 

415 parfilelocs : list of `pathlib.Path`, default=[] 

416 The paths to the files whose contents are in the pardicts list, 

417 in the same order. 

418 

419 Returns 

420 ------- 

421 names : list of `pathlib.Path` 

422 The path to the desired file 

423 """ 

424 

425 if pardicts is None: 

426 pardicts = [] 

427 if parfilelocs is None: 

428 parfilelocs = [] 

429 

430 dicts = [cmd_pardict] 

431 flocs = [FileLocations.cwd] 

432 

433 for dict_, floc in zip(pardicts, parfilelocs): 

434 if dict_: 

435 dicts.append(dict_) 

436 flocs.append(floc.parent) 

437 

438 for dict_, floc in zip(dicts, flocs): 

439 if file_parname in dict_: 

440 names = [floc / name for name in dict_[file_parname]] 

441 break 

442 else: 

443 names = [floc_hc / name for name in files_hc] 

444 

445 return names

448def get_def_parfile( 

449 cmd_pardict, in_parfile=None, in_pardict=None 

450): 

451 """ 

452 Given the parameter information on the command line, and, 

453 optionally, an input parameters file and its contents, finds out the 

454 location of the default parameters file. 

455 

456 If the user specified anything (either the sourcedir or the name of 

457 the default parameter file), the program checks that. If nothing is 

458 present there or if it isn't a file, an error is raised, and the 

459 program quits. 

460 

461 Parameters 

462 ---------- 

463 cmd_pardict : dict 

464 The dict storing the parameter choices from the command line. 

465 in_parfile : `pathlib.Path` or NoneType, default=None 

466 The filename of the input parameter file. 

467 in_pardict : dict, default={} 

468 The parameters supplied in the input parameter file. 

469 """ 

470 

471 files = FileLocations 

472 if in_pardict is None: 

473 in_pardict = {} 

474 

475 name, file_is_hc = get_file( 

476 "source_directory", "default_parameter_filename", 

477 files.sourcedir_hc, [files.refparfilename_hc], 

478 cmd_pardict, [in_pardict], [in_parfile] 

479 ) 

480 

481 file_found = try_file(name[0]) 

482 

483 if not file_found: 

484 GM_pt.Printer.warning( 

485 f"\nThe requested default parameter file {name} could not be " 

486 "found, or is not a file. " 

487 "Please make sure you specified it correctly.\n", 

488 "SU_FH_1", True, GMAPerrclass=GM_ex.GmapFileNotFoundError 

489 ) 

490 

491 # We need a file to check if the default file is complete (AIM did this 

492 # using hard-coded parameters) 

493 if file_is_hc: 

494 check_file_found = file_found 

495 else: 

496 name = files.sourcedir_hc / files.refparfilename_hc 

497 check_file_found = try_file(name) 

498 if not check_file_found: 

499 GM_pt.Printer.warning( 

500 "\nThe requested default parameter file requires the presence " 

501 f"of the file {name}, but this file could not be found. " 

502 "Please make sure you specified it correctly.\n", 

503 "SU_FH_2", True, GMAPerrclass=GM_ex.GmapFileNotFoundError 

504 ) 

505 

506 return file_found

509def try_file(fname): 

510 """Checks if the given location exists, and is a file. 

511 

512 If so, returns pathlib.Path.resolve(location), otherwise, returns 

513 None. Does not check whether the file is of a readable format. 

514 

515 .. seealso:: 

516 :func:`check_file_readability` 

517 Checks whether the given file can actually be read. 

518 

519 Parameters 

520 ---------- 

521 fname : `pathlib.Path` 

522 The path to check 

523 

524 Returns 

525 ------- 

526 fname : `pathlib.Path` or None 

527 The resolved path, or, if the input doesn't exist, None. 

528 """ 

529 

530 if fname.is_file(): 

531 return fname.resolve() 

532 else: 

533 return None

536def check_file_readability(fname, doprint=True, doquit=True): 

537 """Checks if a given file can be read. 

538 

539 If not, lets GM_pt.Printer raise the appropriate error. 

540 

541 .. seealso:: 

542 :func:`try_file` 

543 Checks the existence and file-ness of a given path. 

544 

545 Parameters 

546 ---------- 

547 fname : `pathlib.Path` 

548 The path to the file to check. 

549 doprint : bool, default=True 

550 Whether failure of this test should be reported to the user. 

551 doquit : bool, default=True 

552 Whether the program should raise an error if the file fname is 

553 not readable to the program. 

554 

555 Returns 

556 ------- 

557 is_readable : bool 

558 Whether the file is readable. 

559 """ 

560 

561 try: 

562 with open(fname, 'r', encoding='utf-8') as file: 

563 for _ in file: 

564 pass 

565 except UnicodeDecodeError: 

566 if doprint: 

567 GM_pt.Printer.warning( 

568 f"\n The file {fname} is of the wrong type, please make sure " 

569 "it is a plain text file. ", 

570 "SU_FH_3", doquit, GMAPerrclass=GM_ex.GmapUnicodeDecodeError 

571 ) 

572 return False 

573 return True

576def write_output(run_pars, framenum, outputs): 

577 """Write the output for a single frame to files. 

578 

579 Writes all outputs - all (requested) datastructures in all 

580 (requested) formats. 

581 

582 Parameters 

583 ---------- 

584 run_pars : :class:`~GMAP.src.tools.parameter_parser.RunPars` 

585 The 'main' RunPars instance containing all the basic 

586 run-defining parameters. 

587 framenum : int 

588 The number of the frame currently being written 

589 outputs : dict of str: `np.ndarray` pairs 

590 The outputs the program is requested to generate. Currently 

591 contains hamiltonian and dipole arrays. 

592 """ 

593 

594 framenum_arr = np.array([framenum], dtype='float32') 

595 

596 if "ham" in run_pars.output_data: 

597 hamiltonian = outputs["hamiltonian"] 

598 hamiltonian *= run_pars.hamiltonian_multiplier 

599 reshaped = hamiltonian[np.triu_indices_from(hamiltonian)] 

600 write_single( 

601 run_pars, framenum, framenum_arr, 

602 run_pars.output_hamiltonian_filename, reshaped 

603 ) 

604 

605 if "ene" in run_pars.output_data: 

606 energies = outputs["energies"] 

607 energies *= run_pars.energies_multiplier 

608 write_single( 

609 run_pars, framenum, framenum_arr, 

610 run_pars.output_energies_filename, energies 

611 ) 

612 

613 if "dip" in run_pars.output_data: 

614 dipoles = outputs["dipoles"] 

615 dipoles *= run_pars.dipoles_multiplier 

616 reshaped = dipoles.T.flatten() 

617 write_single( 

618 run_pars, framenum, framenum_arr, 

619 run_pars.output_dipole_filename, reshaped 

620 ) 

621 

622 if "ram" in run_pars.output_data: 

623 raman = outputs["raman"] 

624 raman *= run_pars.raman_multiplier 

625 reshaped = raman.T.flatten() 

626 write_single( 

627 run_pars, framenum, framenum_arr, 

628 run_pars.output_raman_filename, reshaped 

629 ) 

630 

631 if "pos" in run_pars.output_data: 

632 positions = outputs["positions"] 

633 positions *= run_pars.positions_multiplier 

634 reshaped = positions.T.flatten() 

635 write_single( 

636 run_pars, framenum, framenum_arr, 

637 run_pars.output_positions_filename, reshaped 

638 ) 

639 

640 if "dbp" in run_pars.output_data: 

641 doublepos = outputs["doublepos"] 

642 doublepos *= run_pars.doublepos_multiplier 

643 reshaped = doublepos.T.flatten() 

644 write_single( 

645 run_pars, framenum, framenum_arr, 

646 run_pars.output_doublepos_filename, reshaped 

647 )

650def write_single(run_pars, framenum, framenum_arr, fname, data): 

651 """Write a single datastructure to files of given name. 

652 

653 Writes to all different requested formats at once. 

654 

655 Parameters 

656 ---------- 

657 run_pars : :class:`~GMAP.src.tools.parameter_parser.RunPars` 

658 The 'main' RunPars instance containing all the basic 

659 run-defining parameters. 

660 framenum : int 

661 The number of the frame currently being written 

662 framenum_arr : `np.ndarray` 

663 The framenumber as float32 array, ready for binary writing 

664 fname : `pathlib.Path` 

665 The name + location of the file to which to write. This filename 

666 should not include the extension! 

667 data : `np.ndarray` 

668 The data that should be written to the file. 

669 """ 

670 

671 if "bin" in run_pars.output_format: 

672 with open(fname.parent / f"{fname.name}.bin", "ab") as fhand:

814 with open( 

815 pairs_map.directory / "parameters.ref", "r" 

816 ) as reffhand: 

817 write_single_parameter_source( 

818 reffhand, pairs_map.run_pars, outfhand, pairs_map.name, 

819 pairs_map.cmd_pars, pairs_map.in_pars, pairs_map.def_pars)

822def write_single_parameter_source( 

823 reffhand, run_pars, outfhand, sourcename, cmd_pars, in_pars, def_pars 

824): 

825 """Save the parameters of a single source to a file so the run can 

826 be repeated. 

827 

828 Parameters 

829 ---------- 

830 reffhand : `_io.TextIOWrapper` 

831 The reference parameter file handle which contains all 

832 parameters that should be written. 

833 run_pars : :class:`~GMAP.src.tools.parameter_parser.RunPars` 

834 The 'main' RunPars instance containing all the basic 

835 run-defining parameters. 

836 outfhand : `_io.TextIOWrapper` 

837 The output parameter file handle to which all parameters should 

838 be written. 

839 sourcename : str 

840 The name of the source (GMAP or name of map) whose parameters 

841 should be saved. 

842 cmd_pars : :class:`RawPars` 

843 Contains any parameter choices made on the command line 

844 in_pars : :class:`RawPars` 

845 Contains any parameter choices made in the input parameter file 

846 def_pars : :class:`RawPars` or :class:`RefPars` 

847 Contains all default parameter choices. Might be ref_pars, might 

848 be from a separate default parameters file. 

849 """ 

850 

851 write_parameter_header(sourcename, outfhand) 

852 

853 # A select few parameters can be multiline 

854 sp_choices = [] 

855 sp_prname = None 

856 

857 for line in reffhand: 

858 # Find name of parameter on this line 

859 linelist = line.split("#") 

860 parname = linelist[0].split("[")[0].split("(")[0] 

861 # find full (source-including) parameter name 

862 prparname = get_full_parameter_name(parname, sourcename) 

863 

864 # if this line does not contain a parameter 

865 if not hasattr(run_pars, parname): 

866 outfhand.write(line) 

867 continue 

868 

869 # we expect all occurences of the same parameter to be back-to-back 

870 # in a parameter file. So if we've got more lines availabe that 

871 # haven't been printed yet, print them now. 

872 if len(sp_choices) > 0 and sp_prname != prparname: 

873 while len(sp_choices) > 0: 

874 choice = sp_choices.pop(0) 

875 write_parameter_line( 

876 outfhand, sp_prname, choice, []) 

877 sp_prname = None 

878 

879 # write all parameters that are not expected to occur multiple times 

880 sp_choices, sp_prname = write_parameter_line_main( 

881 run_pars, parname, prparname, sp_prname, outfhand, linelist, 

882 cmd_pars, in_pars, def_pars) 

883 

884 outfhand.write("\n\n\n")

887def write_parameter_header(sourcename, outfhand): 

888 """Write the header of the next parameter source to the output file. 

889 

890 Parameters 

891 ---------- 

892 sourcename : str 

893 The name of the source (GMAP or name of map) whose parameters 

894 should be saved. 

895 outfhand : `_io.TextIOWrapper` 

896 The output parameter file handle to which all parameters should 

897 be written. 

898 """ 

899 

900 header = GM_sc.Header( 

901 f"\n{sourcename}\n", linemode="oulrc", padding=3, corner_char="╔╗╚╝",

903 ).cs.change_color("white") 

904 header = "# " + "\n# ".join(header.split("\n")) 

905 outfhand.write(f"\n{header}\n")

929def write_parameter_line_main( 

930 run_pars, parname, prparname, sp_prname, outfhand, linelist, 

931 cmd_pars, in_pars, def_pars 

932): 

933 """Save the parameters of a single source to a file so the run can 

934 be repeated. 

935 

936 Parameters 

937 ---------- 

938 run_pars : :class:`~GMAP.src.tools.parameter_parser.RunPars` 

939 The 'main' RunPars instance containing all the basic 

940 run-defining parameters. 

941 parname : str 

942 The parameter that we'd like to write to file. 

943 prparname : str 

944 The full name of the parameter (possibly including source name) 

945 that we'd like to write to file. 

946 sp_prname : The full name of the special parameter that we treated 

947 last. 

948 outfhand : `_io.TextIOWrapper` 

949 The output parameter file handle to which all parameters should 

950 be written. 

951 linelist : list of str 

952 The line from the reference parameter file, split on "#". 

953 cmd_pars : :class:`RawPars` 

954 Contains any parameter choices made on the command line 

955 in_pars : :class:`RawPars` 

956 Contains any parameter choices made in the input parameter file 

957 def_pars : :class:`RawPars` or :class:`RefPars` 

958 Contains all default parameter choices. Might be ref_pars, might 

959 be from a separate default parameters file. 

960 """ 

961 

962 # parname structures for special parameters 

963 all_inf_pars = set(( 

964 "influencers_whitelist", "influencers_blacklist", "influencers_file", 

965 "influencers_select_atoms")) 

966 all_unit_ends = set(("_units", "_multiplier")) 

967 

968 choice = getattr(run_pars, parname) 

969 # Write parameters that are allowed to occur multiple times 

970 if ( 

971 isinstance(choice, list) 

972 and len(choice) > 0 # so we write entire parameter on first occurence 

973 and isinstance(choice[0], list) 

974 ): 

975 if prparname != sp_prname: 

976 sp_choices = choice[:] 

977 sp_prname = prparname 

978 choice = sp_choices.pop(0) 

979 write_parameter_line(outfhand, prparname, choice, linelist) 

980 return sp_choices, sp_prname 

981 

982 # Write C-library parameters 

983 # ( prparname instead of parname to make sure we only look at GMAP own's 

984 # parameters 

985 elif prparname.endswith("_clib_file"): 

986 choice = str(choice.resolve()) 

987 choice = "_".join(choice.split("_")[:-1]) 

988 write_parameter_line(outfhand, prparname, choice, linelist) 

989 

990 # Write influencer parameters 

991 elif prparname.startswith("influencers_"): 

992 if prparname != "influencers_whitelist": 

993 return [], sp_prname 

994 write_parameter_intersect( 

995 outfhand, prparname, cmd_pars, in_pars, def_pars, all_inf_pars, 

996 linelist) 

997 

998 # Write unit-specifying parameters 

999 elif ( 

1000 any(prparname.startswith(item) for item in ( 

1001 "hamiltonian_", "energies_", "dipoles_", "raman_", 

1002 "positions_", "doublepos_")) 

1003 and any(prparname.endswith(item) for item in all_unit_ends) 

1004 ): 

1005 # ignore the units, only print multiplier (in case of defpars) 

1006 if prparname.endswith("_units"): 

1007 return [], sp_prname 

1008 parnames = [prparname.split("_")[0] + item for item in all_unit_ends] 

1009 write_parameter_intersect( 

1010 outfhand, prparname, cmd_pars, in_pars, def_pars, parnames, 

1011 linelist) 

1012 

1013 # Write 'normal' / other parameters. 

1014 else: 

1015 # now, all special multiline-parameters have been taken care of, 

1016 # so continue to print this new one. 

1017 write_parameter_line(outfhand, prparname, choice, linelist) 

1018 return [], sp_prname

1021def write_parameter_line(outfhand, prparname, choice, linelist): 

1022 """Write a single parameter line to the output file. 

1023 

1024 Parameters 

1025 ---------- 

1026 outfhand : `_io.TextIOWrapper` 

1027 The output parameter file handle to which all parameters should 

1028 be written. 

1029 prparname : str 

1030 The full name of the parameter (possibly including source name) 

1031 that we'd like to write to file. 

1032 choice : any 

1033 The choice as saved in run_pars for this parameter 

1034 linelist : list of str 

1035 The line from the reference parameter file, split on "#". 

1036 """ 

1037 

1038 if isinstance(choice, list): 

1039 if len(choice) == 0: 

1040 choice = ["None"] 

1041 choice = " ".join([str(item) for item in choice]) 

1042 

1043 outfhand.write(f"{prparname:<40} {choice} ") 

1044 if len(linelist) > 1: 

1045 outfhand.write("#" + "#".join(linelist[1:])) 

1046 else: 

1047 outfhand.write("\n")

1050def write_parameter_intersect( 

1051 outfhand, prparname, cmd_pars, in_pars, def_pars, parnames, linelist 

1052): 

1053 """Save a single parameter. This one has multiple options in the 

1054 reference file, of which only one may be written. 

1055 

1056 Each possible parameter source is searched for all valid parameters. 

1057 The first one found will be the one written to file. 

1058 

1059 Parameters 

1060 ---------- 

1061 outfhand : `_io.TextIOWrapper` 

1062 The output parameter file handle to which all parameters should 

1063 be written. 

1064 prparname : str 

1065 The full name of the parameter (possibly including source name) 

1066 that we'd like to write to file. 

1067 cmd_pars : :class:`RawPars` 

1068 Contains any parameter choices made on the command line 

1069 in_pars : :class:`RawPars` 

1070 Contains any parameter choices made in the input parameter file 

1071 def_pars : :class:`RawPars` or :class:`RefPars` 

1072 Contains all default parameter choices. Might be ref_pars, might 

1073 be from a separate default parameters file. 

1074 parnames : iterable 

1075 The parameter names that are an acceptable substitute for 

1076 prparname when looking through the source 

1077 linelist : list of str 

1078 The line from the reference parameter file, split on "#". 

1079 """ 

1080 

1081 for parsource in (cmd_pars, in_pars): 

1082 intersection = set(parnames).intersection(parsource.choices) 

1083 if len(intersection) > 0: 

1084 parameter = intersection.pop() 

1085 write_parameter_line( 

1086 outfhand, parameter, parsource.choices[parameter], []) 

1087 return 

1088 # if no source mentions any influencers 

1089 write_parameter_line( 

1090 outfhand, prparname, def_pars.choices[prparname], linelist)

1093def merge_files(run_pars): 

1094 """Merge output files from multiple runs. 

1095 

1096 Log files from child-runs are pasted to the end of the one of the 

1097 original run (and the originals removed). Parameter files from child 

1098 runs are just removed. Output files are, just as log files, copied 

1099 to the end of the corresponding parent-run file. 

1100 

1101 Parameters 

1102 ---------- 

1103 run_pars : :class:`~GMAP.src.tools.parameter_parser.RunPars` 

1104 The 'main' RunPars instance containing all the basic 

1105 run-defining parameters. 

1106 """ 

1107 

1108 data_to_fname = { 

1109 "ham": "output_hamiltonian_filename", 

1110 "dip": "output_dipole_filename", 

1111 "ene": "output_energies_filename", 

1112 "pos": "output_positions_filename", 

1113 "dbp": "output_doublepos_filename", 

1114 "ram": "output_raman_filename" 

1115 } 

1116 

1117 # merge log files 

1118 dest_fname = run_pars.log_filename 

1119 with open(dest_fname, "a", encoding='utf-8') as fdst: 

1120 for cpu_num in range(run_pars.number_cores): 

1121 source_fname = fname_to_tempname("logfile", run_pars, cpu_num) 

1122 with open(source_fname, encoding='utf-8') as fsrc: 

1123 shutil.copyfileobj(fsrc, fdst) 

1124 Path(source_fname).unlink() 

1125 

1126 # remove parameter files 

1127 for cpu_num in range(run_pars.number_cores): 

1128 parfile = fname_to_tempname("parfile", run_pars, cpu_num) 

1129 Path(parfile).unlink() 

1130 

1131 # merge all requested data output files 

1132 for output_type in run_pars.output_format: 

1133 mode = "b" if output_type == "bin" else "" 

1134 suff = ".bin" if output_type == "bin" else ".txt" 

1135 encoding = None if output_type == "bin" else "utf-8" 

1136 for treat_data in run_pars.output_data: 

1137 dest_fname = getattr(run_pars, data_to_fname[treat_data]) 

1138 with open( 

1139 str(dest_fname) + suff, "w" + mode, encoding=encoding 

1140 ) as fdst: 

1141 for cpu_num in range(run_pars.number_cores): 

1142 source_fname = str(fname_to_tempname( 

1143 treat_data, run_pars, cpu_num)) + suff 

1144 with open( 

1145 source_fname, "r" + mode, encoding=encoding 

1146 ) as fsrc: 

1147 shutil.copyfileobj(fsrc, fdst) 

1148 Path(source_fname).unlink() 

1149 

1150 # after deleting all files, make sure to delete tempdir! 

1151 if any(run_pars.parrun_directory.iterdir()): 

1152 GM_pt.Printer.warning( 

1153 f"The directory {run_pars.parrun_directory} was temporarily made " 

1154 "by GMAP. However, it can now not safely be removed. Please take " 

1155 "a look at this directory yourself.", 

1156 "PF_MD_1", GMAPerrclass=GM_ex.GmapValueError) 

1157 else: # directory is empty, it can safely be removed 

1158 run_pars.parrun_directory.rmdir()

1161def fname_to_tempname(output_data, run_pars, CPU): 

1162 """Generate the temporary file names used for parallel threads based 

1163 on required file type, a run_pars instance, and CPU number. 

1164 

1165 Parameters 

1166 ---------- 

1167 output_data : str 

1168 ham/dip/ene/etc 

1169 run_pars : dict or :class:`~GMAP.src.tools.parameter_parser.RunPars` 

1170 The 'main' RunPars instance containing all the basic 

1171 run-defining parameters. If this is not available (due to 

1172 certain module functions not allowing custom classes), this 

1173 parameter should contain the output of run_pars.parallel_dict. 

1174 CPU : int 

1175 The number of the CPU responsible for the file location created 

1176 by this function. 

1177 

1178 Returns 

1179 ------- 

1180 fpath : `pathlib.Path` 

1181 The filename that should be used for the requested function. 

1182 """ 

1183 

1184 data_to_fname = { 

1185 "ham": "output_hamiltonian_filename", 

1186 "dip": "output_dipole_filename", 

1187 "ene": "output_energies_filename", 

1188 "pos": "output_positions_filename", 

1189 "dbp": "output_doublepos_filename", 

1190 "ram": "output_raman_filename", 

1191 "parfile": "output_parameter_filename", 

1192 "logfile": "log_filename" 

1193 } 

1194 

1195 if isinstance(run_pars, dict): 

1196 parent = run_pars["parrun_directory"] 

1197 path = run_pars[data_to_fname[output_data]]
